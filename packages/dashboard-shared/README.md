# @all-in-one-mcp/dashboard-shared

Shared Vue dashboard UI consumed by both desktop and web apps.

## Purpose

- dashboard root shell
- shared components
- shared composables
- shared dashboard types
- shared CSS tokens and layout styles

## Public exports

- `DashboardRoot`
- dashboard composables and client interfaces
- dashboard types and formatters
- `@all-in-one-mcp/dashboard-shared/styles.css`

## Consumers

- `apps/dashboard`
- `apps/tauri-vue`
