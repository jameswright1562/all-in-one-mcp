# Security Policy

## Reporting

Report security issues privately to the maintainers before opening a public issue or pull request.

Include:

- affected package or app
- reproduction steps
- impact assessment
- suggested remediation if known

## Supported Scope

Security fixes apply to:

- `packages/contracts`
- `packages/shared`
- `packages/runtime`
- `packages/dashboard-shared`
- `apps/dashboard`
- `apps/tauri-vue`
